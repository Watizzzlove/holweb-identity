## 📌 О проекте и концепциях

В презентации исследованы и объединены два ключевых концептуальных направления:

### 1. Направление: «Лента Мёбиуса» (Möbius Flow)
- **Идея**: Непрерывный замкнутый цикл услуг (*Full-Cycle Web*).
- **Стилистические вариации**:
  - Авторский ручной эскиз (слитная строка `Holweb` в наклонном 2D-пикселе + монограмма H);
  - 3D Volumetric Loop (кинематографичный атласно-металлический перекрут со светотенью);
  - 2D Flat Geometric (минималистичный векторный контур);
  - 16-bit & 8-bit Pixel Series (исследование шага пиксельной лестницы и наклона);
  - 3D Voxel (воксельные ступени роста).

### 2. Направление: «Греческий Меандр» (Greek Meander & Kuptsoft Style)
- **Идея**: Античный холизм (*holos* — целое больше суммы частей) + архитектурная устойчивость (*hold*).
- **Стилистические вариации**:
  - 3 авторских ручных начертания `HOLWEB` (лазурный контур с точкой в W, черный монолит, контурная обводка);
  - Классический симметричный Нео-Меандр H (греческий ключ 90°);
  - Динамический меандр со сдвигом фаз;
  - Горизонтальная непрерывная магистраль `HOLWEB`;
  - Двухуровневый монолит `HOL / WEB` по модульной сетке KUPTSOFT.

## 🛠 Дизайн-система Kwork
В проекте реализованы носители по ТЗ заказчика:
- **Главный баннер профиля Kwork** (архитектурная темная сетка, золотистые акценты, плашки 3650+ заказов и 5.0 рейтинг).
- **Модульные карточки кворков** в 3 форматах (прямоугольный 3:2, квадрат 1:1, вертикальный 9:16) со светлым фоном, UPPERCASE-типографикой и изолированными 3D-объектами.
